# לאנצר ירפ"א – תוכנה להתקנה במחשב

זו תוכנת הלאנצר (כמו של מיינקראפט): המשתמש מתקין אותה, מתחבר עם שם משתמש וסיסמה,
הסימולטור יורד למחשב בפעם הראשונה, ומשם משחקים. השרת (`../server.js`) הוא שמחליט
מי מקבל גישה ומתי היא נחסמת.

## איך זה עובד
- הלאנצר מתחבר לשרת שלך (אותו שרת של פאנל הניהול) ומקבל אסימון כניסה. אם מסמנים "זכור אותי", האסימון נשמר מוצפן בעזרת מנגנון ההצפנה של Windows.
- בלחיצה על "שחק" הסימולטור יורד **מוצפן** ונשמר במחשב. בפעם הבאה הוא כבר שם, ואם עדכנת את הקובץ בשרת הוא מתעדכן לבד.
- את מפתח הפתיחה השרת נותן רק ברגע ההפעלה, ורק אם הגישה בתוקף. הסימולטור נפתח בזיכרון בלבד.
- בזמן המשחק הלאנצר בודק מול השרת כל 20 שניות. חסימה או סוף התקופה סוגרים את חלון הסימולטור. ניתוק אינטרנט של כדקה ברצף סוגר אותו גם כן.
- הגדרות הסטיק והמצערת נשמרות בין הפעלות.
- F11 מעביר את חלון הסימולטור למסך מלא.

## הגדרה לפני בנייה
בקובץ `config.json` כתוב את כתובת השרת שלך (אותה כתובת Railway מהשרת):
```json
{ "server": "https://yarpa-xxxx.up.railway.app" }
```
ובשרת עצמו ודא שמשתנה הסביבה `ALLOW_WEB_PLAY` **לא** מוגדר ל-1, כדי שהמשחק יהיה רק דרך הלאנצר.

## דרך קלה לבנות את קובץ ההתקנה ל-Windows (GitHub, בלי להתקין כלום)
בניית תוכנת Windows דורשת מחשב Windows או שירות בנייה. הכי פשוט דרך GitHub:
1. העלה את התיקייה `launcher-app` הזו ל-repository ב-GitHub (הקובץ `.github/workflows/build.yml` כבר כלול).
2. ב-GitHub, לשונית **Actions** → בחר **Build Windows launcher** → **Run workflow**.
3. אחרי כמה דקות, הורד מתוך ה-run את **YarpaLauncher-Windows** — זהו קובץ ההתקנה `YarpaLauncher-Setup-1.0.0.exe`.
4. את הקובץ הזה אתה שולח למכון נועם (או מעלה לאחסון ושם את הקישור במשתנה `DOWNLOAD_URL` בשרת, כדי שיופיע כפתור הורדה בעמוד הבית).

## לבנות על מחשב Windows משלך (במקום GitHub)
1. התקן Node.js 20.
2. בתיקייה הזו: `npm install` ואז `npm run dist`.
3. קובץ ההתקנה ייווצר בתיקייה `dist`.

## להריץ לבדיקה לפני בנייה (על מחשב מפתח)
`npm install` ואז `npm start` — הלאנצר ייפתח ויתחבר לשרת שב-`config.json`.
לבדיקה מול שרת מקומי אפשר: `YARPA_SERVER=http://localhost:3000 npm start`.

## אייקון (אופציונלי)
אם תרצה אייקון משלך לתוכנה, שים קובץ `build/icon.ico` (256×256) והוסף ב-`package.json`
תחת `build.win` את השורה `"icon": "build/icon.ico"`. בלי זה ייבנה עם אייקון ברירת מחדל.
