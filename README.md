# לאנצר ירפ"א – שרת רישוי + לאנצר להתקנה במחשב

בחבילה שני חלקים:
1. **השרת** (התיקייה הזו): מחזיק את המשתמשים, מאשר כניסות, שולח את הסימולטור ללאנצר וחוסם גישה. כולל **פאנל ניהול** (`/admin`).
2. **הלאנצר להתקנה** (`launcher-app/`): התוכנה שמכון נועם מתקינים במחשב, כמו הלאנצר של מיינקראפט. ההוראות לבנייתה בקובץ `launcher-app/README.md`.

### שתי דרכים לשחק
- **ברירת מחדל – לאנצר במחשב בלבד:** המשתמש מתקין את התוכנה, מתחבר, והסימולטור יורד ומופעל מהמחשב. עמוד הבית של השרת (`/`) מציג עמוד הורדה.
- **אופציונלי – דרך הדפדפן:** אם תגדיר בשרת `ALLOW_WEB_PLAY=1`, יופעלו גם מסך כניסה (`/`) ולאנצר בדפדפן (`/launcher`), בלי התקנה. אפשר להפעיל את שתי הדרכים יחד.

## איך זה מגן על הסימולטור
- הסימולטור יורד רק דרך הלאנצר, ורק למשתמש שמחובר ובתוקף. אין קישור ישיר להורדה.
- **הקובץ נשמר במחשב מוצפן.** את מפתח הפתיחה השרת נותן רק ברגע הלחיצה על "שחק", ורק אם הגישה בתוקף. הסימולטור נפתח בזיכרון ולא נשמר אף פעם על הדיסק כקובץ קריא. אחרי שהשבוע נגמר, הקובץ שנשאר במחשב לא שימושי.
- בזמן המשחק הלאנצר בודק מול השרת כל 20 שניות. כשחוסמים משתמש או כשהתקופה נגמרת, חלון הסימולטור נסגר. אם החיבור לאינטרנט נופל לכדקה ברצף, המשחק נסגר וצריך חיבור כדי לפתוח שוב. ניתוק קצר לא מפריע.
- **מכשירים במקביל**: כברירת מחדל 2. כניסה ממחשב נוסף מעבר למכסה מנתקת את המחשב הישן ביותר.
- על כל מסך מופיע סימן מים קטן עם שם בעל הרישיון.

> **מגבלה שחשוב להכיר:** בזמן שהגישה בתוקף, מתכנת מנוסה מאוד יכול לפרוץ ללאנצר ולחלץ ממנו את
> הסימולטור. זה נכון לכל לאנצר, גם של מיינקראפט. ההצפנה מונעת את המקרה הנפוץ (להעתיק את הקובץ
> מהמחשב ולהשתמש בו אחרי שהשבוע נגמר). בשביל מכון נועם עדיין מומלץ הסכם ניסיון קצר שאוסר העתקה.

## שלב 1 – להכניס את הסימולטורים
העתק את שני קבצי הסימולטור לתיקייה `games` ותן להם בדיוק את השמות האלה:
- `games/yarpa-a.html` ← הסימולטור של ירפ"א א'
- `games/yarpa-b.html` ← הסימולטור של ירפ"א ב'

כדי לעדכן סימולטור, פשוט מחליפים את הקובץ. השמות והתיאורים שבלאנצר נמצאים בקובץ `games.json`.

## משתני סביבה בשרת
- `ADMIN_PASSWORD` (חובה) – סיסמת פאנל הניהול.
- `DATA_DIR` – היכן נשמרים המשתמשים (ב-Railway: `/data`).
- `ALLOW_WEB_PLAY=1` – להפעיל גם משחק דרך הדפדפן (לא חובה).
- `LICENSE_SECRET` – לא חובה. אם לא מוגדר, השרת יוצר מפתח הצפנה אקראי ושומר אותו ב-`DATA_DIR`.
- `DOWNLOAD_URL` – קישור לקובץ ההתקנה של הלאנצר; אם תגדיר, יופיע כפתור הורדה בעמוד הבית.

## שלב 2 – לנסות אצלך במחשב (5 דקות)
1. התקן Node.js (גרסה 18 ומעלה) מהאתר nodejs.org.
2. פתח חלון פקודה (cmd) בתיקייה הזו והרץ:
   ```
   set ADMIN_PASSWORD=בחר-סיסמת-מנהל-ארוכה
   node server.js
   ```
   (ב-Mac או Linux: `ADMIN_PASSWORD=... node server.js`)
3. גלוש ל-`http://localhost:3000/admin`, היכנס עם סיסמת המנהל וצור משתמש לניסיון.
4. לבדיקת הלאנצר עצמו, ראה `launcher-app/README.md` (אפשר להריצו מול השרת המקומי).

## שלב 3 – להעלות לאינטרנט (Railway)
כדי שמכון נועם יוכלו להיכנס, השרת צריך לרוץ באינטרנט. מומלץ **Railway**, כי יש לו אחסון קבוע (Volume) שבו נשמרת רשימת המשתמשים.

> ⚠️ לא מומלץ Render בחינם: שם הקבצים נמחקים בכל הפעלה מחדש, וכל המשתמשים ייעלמו.

1. העלה את התיקייה הזו (כולל `games` עם שני הסימולטורים) ל-repository **פרטי** ב-GitHub.
2. ב-railway.com: **New Project → Deploy from GitHub repo** ובחר את ה-repository.
3. בלשונית **Variables** הוסף:
   - `ADMIN_PASSWORD` = סיסמת מנהל ארוכה (לפחות 12 תווים)
   - `DATA_DIR` = `/data`
4. לחיצה ימנית על השירות → **Attach Volume**. בשדה Mount path כתוב `/data`.
5. ב-**Settings → Networking** לחץ **Generate Domain**. תקבל כתובת כמו `yarpa-xxxx.up.railway.app`.
6. גלוש ל-`https://הכתובת-שלך/admin` וצור את המשתמש של מכון נועם.

## שלב 3.5 – לבנות את הלאנצר ולשלוח אותו
היכנס לתיקייה `launcher-app`, כתוב ב-`config.json` את כתובת השרת מהשלב הקודם, ובנה את קובץ ההתקנה ל-Windows לפי `launcher-app/README.md` (הדרך הקלה: דרך GitHub Actions, בלי להתקין כלום). את קובץ ההתקנה שלח למכון נועם, או העלה אותו לאחסון ושים את הקישור במשתנה `DOWNLOAD_URL`.

## שלב 4 – לתת גישה לשבוע למכון נועם
בפאנל הניהול:
1. שם משתמש: `noam`. שם/ארגון: `מכון נועם`. תקופת גישה: `7`.
2. השאר מסומן "הספירה מתחילה בכניסה הראשונה". כך השבוע שלהם יתחיל רק כשהם באמת נכנסים. אם תבטל את הסימון, השבוע מתחיל כבר עכשיו.
3. לחץ "צור משתמש". תופיע הודעה מוכנה עם הכתובת, שם המשתמש והסיסמה. העתק ושלח להם.

אחרי 7 ימים הגישה נסגרת אוטומטית. בכל רגע אפשר גם:
- **חסום**: ניתוק מיידי ואין אפשרות כניסה, עד ש"שחרר חסימה".
- **הארך**: הוספת ימים, למשל אם ביקשו עוד כמה ימים.
- **סיים גישה**: סוגר את התקופה עכשיו.
- **סיסמה חדשה**: הסיסמה הישנה מפסיקה לעבוד ומי שמחובר מנותק.
